# Code of Conduct

We want this project to be useful, calm, and technically rigorous.

Participants must be respectful across issues, pull requests, reviews, and
other project spaces. Harassment, discrimination, threats, sexualized content,
deliberate humiliation, doxxing, and sustained disruption are not acceptable.

Good technical disagreement is welcome. Critique behavior, evidence, code, and
tradeoffs rather than a person's ability or identity. Respect private
configuration data and remove accidental disclosures promptly.

Maintainers may edit or remove content, reject contributions, temporarily
limit participation, or ban participants when necessary to protect the
community. Enforcement decisions should consider context, impact, and repeated
behavior.

Report conduct concerns privately through the maintainer contact options on
the GitHub profile. Reports will be handled as confidentially as practical.
