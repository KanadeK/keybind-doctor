# Keybind Doctor 0.1.0

The first public release turns real shortcut configs into one explainable
portfolio.

## Highlights

- Imports VS Code, Cursor, Windsurf, Zed, JetBrains, PowerToys, and AutoHotkey
  native formats.
- Separates definite conflict, global shadow, potential overlap, reserved key,
  and proven safe reuse.
- Proves common boolean and equality contexts disjoint without guessing about
  unsupported syntax.
- Generates deterministic, collision-checked, minimum-change repair plans.
- Ships a CI-friendly CLI and a local-only browser workbench.
- Includes JSON, Markdown, CSV, release checksums, reproducible fixtures, and
  failure repair documentation.

## Install

Verify `SHA256SUMS`, then install `keybind-doctor-0.1.0.tgz` with npm. The
standalone web archive contains the same workbench deployed to GitHub Pages.

See [README.md](https://github.com/KanadeK/keybind-doctor#readme) for commands,
exit codes, supported formats, and deliberate limits.
